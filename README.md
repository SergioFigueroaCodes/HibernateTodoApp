# Hibernate To-Do App

A Java command-line To-Do List application that uses Hibernate ORM and MySQL for persistent data storage.

## Features

- Add new tasks
- Display all tasks
- Remove tasks
- Store task data in a MySQL database
- Uses Hibernate ORM for database operations

## Technologies Used

- Java
- Hibernate ORM
- MySQL
- Gradle
- IntelliJ IDEA
- Git & GitHub

## How It Works

The application provides a simple command-line menu where users can add, view, and remove tasks. Hibernate handles communication between the Java application and the MySQL database, allowing tasks to remain stored after the application closes.

## What I Learned

This project helped me practice connecting a Java application to a MySQL database using Hibernate ORM. I also gained experience working with entity classes, Hibernate sessions and transactions, Gradle dependencies, and version control with Git and GitHub.
